# PyWuzzuf-Extractor
A robust Python web scraping tool built with Playwright and BeautifulSoup to extract job listings, details, requirements, and salaries from Wuzzuf, exporting data to CSV.
#  How to Run
 Install dependencies:
    pip install playwright beautifulsoup4 lxml

 Install Playwright browsers:
    playwright install

 Run the script:
    python web_scrabing_optimization.py
